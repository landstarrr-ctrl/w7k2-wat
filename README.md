# 스마트제조혁신 공고 감시 봇

기업마당과 중소벤처기업부 사업공고 게시판을 30분마다 확인해서, 설정한 키워드(스마트공장, 제조AI, 제조로봇, 피지컬AI 등)에 맞는 **새 공고가 올라오면 텔레그램·이메일로 알려 주고**, 모아 본 공고를 **웹 대시보드**로 보여 줍니다. 서버는 GitHub Actions를 쓰므로 비용이 들지 않습니다.

```
GitHub Actions (30분마다)
  ├─ 기업마당 API ─────────┐
  ├─ 중기부 사업공고 게시판 ─┼─ 키워드 일치 → 새 공고? ─ 예 → 텔레그램 / 이메일
  └─ (추가 게시판, 선택) ───┘                         └→ data/state.json 기록
                                                        └→ docs/index.html 대시보드 (GitHub Pages)
```

처음 실행할 때는 이미 올라와 있는 공고를 **알림 없이 기록만** 하고 "감시를 시작했습니다" 메시지 한 통을 보냅니다. 그 뒤로는 새로 올라온 공고만 알려 줍니다. 같은 공고가 기업마당과 중기부 양쪽에 올라오면 한 번만 알리고, 대시보드에 두 출처 링크를 함께 붙입니다.

---

## 설치 순서 (약 1시간)

### 1단계. GitHub 저장소 만들기

1. [github.com](https://github.com)에 가입하고 로그인합니다.
2. 오른쪽 위 **+ → New repository**를 누릅니다.
3. 이름은 `gonggo-watch`처럼 정하고, **Public**을 고릅니다.
   - Public이어야 GitHub Pages 대시보드와 Actions를 무료로 제한 없이 쓸 수 있습니다.
   - 공개되는 것은 공고 목록과 코드뿐이고, API 키·비밀번호는 Secrets에 따로 보관되어 공개되지 않습니다.
4. 저장소가 만들어지면 **uploading an existing file** 링크를 눌러 이 폴더 안의 파일을 모두 끌어다 놓고 **Commit changes**를 누릅니다.
   - `.github` 폴더가 꼭 함께 올라가야 합니다. 맥/윈도우에서 숨김 폴더라 안 보이면 숨김 파일 표시를 켠 뒤 폴더째 끌어다 놓으세요.
   - 올린 뒤 저장소에 `.github/workflows/monitor.yml` 파일이 보이면 정상입니다.

### 2단계. 기업마당 API 키 신청

1. [기업마당(bizinfo.go.kr)](https://www.bizinfo.go.kr) 누리집의 **정책정보 개방(API)** 메뉴에서 사용 신청을 합니다.
2. 신청서의 시스템 정보는 아직 서버가 없으므로 이렇게 적으면 됩니다.
   - 시스템 명: `공고 감시 봇`
   - 시스템 URL: 3단계 이후의 대시보드 주소(`https://아이디.github.io/gonggo-watch/`) 또는 `https://localhost`
   - 시스템 IP: 검색창에 '내 IP'로 확인한 주소
3. 승인되면 발급되는 **인증키**를 메모해 둡니다.

> 키가 아직 없어도 봇은 동작합니다. 그동안은 중기부 사업공고 게시판만 확인하고, 키를 넣는 순간부터 기업마당도 함께 확인합니다.

### 3단계. 알림 받을 곳 준비 (둘 중 하나 또는 둘 다)

**텔레그램 (추천: 휴대폰 푸시가 바로 옴)**

1. 텔레그램에서 `@BotFather`를 찾아 대화를 열고 `/newbot`을 보냅니다.
2. 봇 이름과 아이디(끝이 `bot`)를 정하면 **토큰**(`123456:ABC...`)을 줍니다. 메모합니다.
3. 방금 만든 봇과 대화를 열고 아무 말이나 한 번 보냅니다.
4. 브라우저에서 `https://api.telegram.org/bot<토큰>/getUpdates`를 엽니다.
   결과 안의 `"chat":{"id": 123456789` 숫자가 **채팅 ID**입니다.
   - 팀 단체방에서 받으려면 봇을 단체방에 초대하고 단체방에서 말을 한 번 한 뒤 같은 주소를 열면 됩니다(단체방 ID는 `-`로 시작).

**이메일 (Gmail 기준)**

1. 구글 계정 → 보안에서 **2단계 인증**을 켭니다.
2. 구글 계정 검색창에 **앱 비밀번호**를 검색해 새로 만듭니다(16자리).
3. 평소 로그인 비밀번호가 아니라 이 16자리 앱 비밀번호를 씁니다.

### 4단계. 비밀값(Secrets) 넣기

저장소 **Settings → Secrets and variables → Actions → New repository secret**에서 아래 이름 그대로 추가합니다. 쓰지 않는 채널은 비워 두면 됩니다.

| 이름 | 값 | 필요할 때 |
|---|---|---|
| `BIZINFO_API_KEY` | 기업마당 인증키 | 기업마당 감시 |
| `TELEGRAM_BOT_TOKEN` | BotFather가 준 토큰 | 텔레그램 |
| `TELEGRAM_CHAT_ID` | getUpdates에서 찾은 숫자 | 텔레그램 |
| `SMTP_USER` | 보내는 Gmail 주소 | 이메일 |
| `SMTP_PASSWORD` | 16자리 앱 비밀번호 | 이메일 |
| `MAIL_TO` | 받을 주소(여러 명은 쉼표로) | 이메일, 비우면 보내는 주소로 |
| `SMTP_HOST`, `SMTP_PORT` | Gmail이 아닐 때만 (예: 네이버 `smtp.naver.com`, `465`) | 선택 |

### 5단계. 실행하고 확인하기

1. 저장소의 **Actions** 탭으로 가서, 워크플로를 켜라는 안내가 나오면 켭니다.
2. 왼쪽 **공고 감시** → **Run workflow** → `알림 테스트만 보내기`에 체크 → **Run workflow**.
   텔레그램/메일로 테스트 메시지가 오면 알림 설정은 끝입니다.
3. 다시 **Run workflow**를 체크 없이 실행합니다. 첫 실행이라 "감시를 시작했습니다" 메시지가 오고, 이후 30분마다 자동으로 돕니다.
4. 실행 기록을 눌러 **공고 확인** 단계의 로그를 보면 출처별로 "키워드 일치 N건"이 찍혀 있습니다.

### 6단계. 대시보드 켜기

1. **Settings → Pages**로 갑니다.
2. Source를 **Deploy from a branch**, Branch를 **main**, 폴더를 **/docs**로 고르고 Save.
3. 1~2분 뒤 `https://아이디.github.io/gonggo-watch/`에서 대시보드가 열립니다. 휴대폰 홈 화면에 추가해 두면 편합니다.

## 키워드와 감시 대상 바꾸기

`config.yaml` 파일을 GitHub 화면에서 연필 아이콘으로 고친 뒤 Commit 하면 다음 실행부터 반영됩니다.

- `groups`: 분류(대시보드 탭) 목록. `name`이 탭 이름, `keywords`가 그 탭에 넣을 키워드입니다.
- 키워드 쓰는 법: `스마트공장`(단어 하나), `AI + 제조|공장`(AI가 있고 제조 또는 공장도 있을 때). `+`는 '그리고', `|`는 '또는'.
- 영어 키워드(AI, AX, MES)는 단어 단위로만 잡아서 MAIN, TAX 같은 글자는 무시합니다.
- 키워드를 바꾼 뒤 첫 실행에서 새로 잡힌 기존 공고는 하나씩 알리지 않고 요약 한 통만 보내며, 대시보드에 '신규'로 표시합니다.
- `exclude`: 이 단어가 제목에 있으면 제외. 예) `- 선정결과`
- `match_summary: true`: 기업마당 공고의 사업 요약까지 검색(더 많이 잡히지만 잡음도 늘어남).

감시 주기는 `.github/workflows/monitor.yml`의 `cron: "*/30 * * * *"`에서 바꿉니다(`*/15`면 15분마다).

## 문제 해결

**출처 하나가 계속 실패한다는 경고가 온다**
3회 연속 실패하면 한 번 경고가 옵니다. 원인은 보통 셋 중 하나입니다.
1. 사이트 점검 중 → 저절로 회복됩니다.
2. 게시판 화면 구조가 바뀜 → `monitor.py`의 해당 출처 코드를 고쳐야 합니다.
3. **해외 IP 차단** → GitHub Actions 서버는 해외에 있어서, 일부 정부 사이트가 접속을 막을 수 있습니다. 이 경우 아래 '내 PC에서 돌리기'로 바꾸세요.

**알림은 안 오는데 Actions는 성공으로 뜬다**
로그에 `(알림 채널 미설정)`이 보이면 Secrets 이름이 틀렸거나 비어 있는 것입니다. `텔레그램 오류`가 보이면 토큰이나 채팅 ID를 다시 확인하세요(봇에게 먼저 말을 걸어야 메시지를 받을 수 있습니다).

**알림이 30분보다 늦게 온다**
GitHub의 예약 실행은 붐비는 시간대에 몇 분에서 수십 분 늦어질 수 있습니다. 정확한 시간이 중요하면 내 PC나 국내 서버에서 돌리는 편이 낫습니다.

**대시보드에 예전 공고가 안 보인다**
대시보드에는 최근 300건까지만 남깁니다(`config.yaml`의 `dashboard.keep`).

## 내 PC에서 돌리기 (해외 IP 차단 시)

1. [Python](https://www.python.org) 3.10 이상을 설치합니다(설치 시 'Add to PATH' 체크).
2. 이 폴더에서 명령 프롬프트를 열고 `pip install -r requirements.txt`
3. `.env.example`을 `.env`로 복사하고 값을 채웁니다.
4. `python monitor.py --test-notify`로 알림 테스트, `python monitor.py`로 한 번 실행.
5. **윈도우 작업 스케줄러**에서 '기본 작업 만들기' → 매일, 반복 간격 30분 → 프로그램 `python`, 인수 `monitor.py`, 시작 위치에 이 폴더 경로를 넣습니다.

PC에서 돌리면 대시보드는 `docs/index.html` 파일을 브라우저로 열어서 보면 됩니다. PC가 꺼져 있는 동안은 확인하지 않습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `config.yaml` | 키워드·감시 대상 설정 (여기만 고치면 됨) |
| `monitor.py` | 공고 확인, 알림 전송, 기록 |
| `dashboard.py` | 대시보드 HTML 생성 |
| `.github/workflows/monitor.yml` | 30분마다 자동 실행 |
| `data/state.json` | 이미 본 공고 기록 (자동 생성) |
| `docs/` | 대시보드 (자동 생성) |

이 봇은 공고 확인과 알림만 합니다. 지원 자격이나 일정은 반드시 원문 공고에서 다시 확인하세요.
